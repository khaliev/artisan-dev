## Context & Purpose

When managing large content collections for static websites, validating YAML and JSON schemas manually can be tedious.

`CLI Data Artisan` is a lightweight terminal utility built to automate Zod schema checks before build time.

## Key Features

- Fast schema validation for YAML and JSON files.
- Clean terminal output with actionable error messages.
- Ready for CI/CD integration.
