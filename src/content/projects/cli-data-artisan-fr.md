## Contexte & Besoins

Pendant le développement de sites statiques et la manipulation de schémas de contenu volumineux, la validation manuelle des fichiers de données YAML et JSON s'avère fastidieuse.

`CLI Data Artisan` est un utilitaire léger conçu pour automatiser l'analyse syntaxique et la vérification des types Zod directement dans le terminal.

## Fonctionnalités principales

- Détection rapide des erreurs de schéma dans les fichiers YAML/JSON.
- Export de rapports synthétiques en mode texte ou Markdown.
- Intégration facile dans les pipelines CI/CD.
