## Контекст и задачи

При работе с большими объемами контента в статических сайтах ручная проверка файлов YAML и JSON занимает много времени.

`CLI Data Artisan` — это консольный инструмент для автоматической проверки схем данных Zod прямо в терминале.

## Основные возможности

- Быстрая валидация файлов YAML и JSON.
- Наглядный вывод ошибок в терминал.
- Простая интеграция в CI/CD.
