## Why Eco-Designed Web Development Matters

The digital sector accounts for approximately 4% of global greenhouse gas emissions. Digital sobriety is a core responsibility for modern web developers.

Eco-designing a website means optimizing every asset to reduce server and client-side energy consumption without compromising usability or accessibility.

## Core Pillars of Eco-Design with Astro

Astro has established itself as a leading framework for low-carbon websites thanks to its Islands Architecture.

### 1. Zero JavaScript by Default

Unlike traditional SPA frameworks that ship heavy JavaScript bundles, Astro generates 100% static HTML at build time.

### 2. Selective Hydration

When client-side interactivity is required, Astro allows loading JavaScript only when components enter the viewport (`client:visible`).

### 3. Automated Asset Optimization

Images are converted to modern formats (WebP/AVIF), resized, and lazily loaded automatically.

## Measurable Impact

- Reduced average page weight from **2.5 MB down to under 200 KB**.
- Initial LCP loading time below **0.8 seconds**.
- Eco-index score exceeding **Grade A (85+)**.
