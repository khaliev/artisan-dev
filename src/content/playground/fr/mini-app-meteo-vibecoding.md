## Contexte

Cette mini-application a été conçue lors d'une session de **vibecoding** explorant le prototypage rapide assisté par intelligence artificielle.

## Fonctionnalités

- Récupération des prévisions météo en temps réel via API ouverte.
- Interface épurée avec thème adaptatif selon l'heure locale.
- Zéro framework lourd, architecture 100% vanilla JS.

## Retour d'expérience

Le vibecoding permet d'itérer à grande vitesse sur la structure visuelle et la logique métier tout en gardant le contrôle sur la propreté du code produit.
